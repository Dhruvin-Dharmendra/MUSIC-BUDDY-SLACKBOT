# MUSIC-BUDDY-SLACKBOT

A 24/7 Slack application that brings music discovery and entertainment directly into your Slack workspace. Powered by Node.js, Bolt for JavaScript, and open-source APIs.

Features-

1) /music-buddy-song [song name]: Search for song details, artwork, artist names, and album titles using the iTunes Search API
2) /music-buddy-catfact: Get random, fun cat facts directly in Slack.
3) /music-buddy-joke`**: Get random programming, dad, or general jokes to lighten up the channel.

Built With-

1) Language: Node.js
2) Framework:** [@slack/bolt](https://slack.dev/bolt-js)
3) APIs:
  - [iTunes Search API](https://developer.apple.com/library/archive/documentation/AudioVideo/Conceptual/iTuneSearchAPI/index.html)
  - [JokeAPI](https://v2.jokeapi.dev/) 
  - [Cat Facts API](https://alexwhoops.github.io/cat-facts-api/)
4) Hosting & Deployment: Linux (Debian/Ubuntu) + `systemd`

Runs 24/7-

-[Node.js](https://nodejs.org/) installed on your machine.

-A Slack Workspace where you have permissions to install apps.
